13.1

From Class IX to grouped data

In Class IX you found the mean, median and mode of small lists of numbers. Real data is big: the marks of 2 lakh students, the heights of every girl in a district, the electricity bills of a whole town. So we group it into classes, and this chapter teaches how to find the three “centres” of such grouped data.

x̄ Mean the average

Sum of all values ÷ number of values. Uses every observation.

Median the middle one

The value that splits the data, arranged in order, into two equal halves.

Mode the most popular

The value that occurs most often (highest frequency).

These three are called measures of central tendency: each tries to give one number that represents the whole data.

🤔 Where does a value on the boundary go?

In NCERT, a value equal to an upper limit goes into the next class. So 40 marks is counted in 40–55, not in 25–40. This is the meaning of “10–25, 25–40, …” (classes that share an end point).

13.2

Mean of grouped data: the direct method

If x1, x2, …, xn occur with frequencies f1, f2, …, fn, then x1 occurs f1 times, x2 occurs f2 times, and so on.

x̄ = f1x1 + f2x2 + … + fnxnf1 + f2 + … + fn = Σ fixiΣ fi
Σ (capital sigma, a Greek letter) means “add them all up”, for i = 1 to n.

13.2

Assumed mean and step-deviation methods

When xi and fi are big numbers, multiplying them is slow and error-prone. We cannot change the fi, but we can make the xi smaller by subtracting a fixed number from each of them.

Assumed mean method

  1. Choose one of the xi as the assumed mean a. Pick one near the centre to keep numbers small. Here a = 47.5 (62.5 also works).
  2. Find the deviations di = xi − a.
  3. Find fidi and add them.
  4. Mean of the deviations d̄ = ΣfidiΣfi, and x̄ = a + d̄.

So x̄ = a + d̄, that is

⭐ Activity 1: does the choice of a matter?

Take a = 17.5, then 32.5, then 62.5 … You get 62 every time. The value of the mean does not depend on the choice of a, because whatever we subtract we add back. Try it in Tool 2 below.

Step-deviation method

In Table 13.4 every di is a multiple of 15 (the class size). Divide them by 15 to get even smaller numbers:

ui = xi − ah
a = assumed mean, h = class size

Why x̄ = a + h ū

✍️ Remember

  • Step-deviation is handy when all the di have a common factor.
  • All three methods give the same mean. The assumed mean and step-deviation methods are just simplified forms of the direct method.
  • x̄ = a + hū still holds if a and h are any non-zero numbers with ui = xi − ah. That is why it works even for unequal classes (Example 3).

13.3

Mode of grouped data

The mode is the value with the maximum frequency. If two or more values share the maximum, the data is multimodal (we only take problems with one mode).

Example 4: ungrouped data first

Wickets taken by a bowler in 10 matches: 2, 6, 4, 5, 0, 2, 1, 3, 2, 3.

Wickets0123456
Matches1132111

2 wickets came in the most matches (3), so the mode is 2.

The modal class and the mode formula

In grouped data we can only spot the class with the highest frequency, the modal class. The mode is a value inside it:

Mode = l + (f1 − f02f1 − f0 − f2) × h
Only for classes of equal size.

l lower limit of the modal class

h size of the class interval

f1 frequency of the modal class

f0 frequency of the class before (preceding) the modal class

f2 frequency of the class after (succeeding) the modal class

Example 5: family size of 20 households

Family size1–33–55–77–99–11
Families78221
Sol.Modal class 3–5 (frequency 8).

l = 3, h = 2, f1 = 8, f0 = 7, f2 = 2.

Mode = 3 + (8 − 716 − 7 − 2) × 2 = 3 + 27 = 3.286

Example 6: mode of Table 13.3, compared with the mean

Sol.Modal class 40–55 (7 students).

l = 40, h = 15, f1 = 7, f0 = 3, f2 = 6.

Mode = 40 + (7 − 314 − 6 − 3) × 15 = 40 + 12 = 52

The largest number of students scored about 52, while on average a student scored 62 (the mean).

🤔 Remarks from the book

  • Here mode < mean, but in other data the mode can be equal to or bigger than the mean.
  • “Average marks of all students” → use the mean. “The marks most students got” → use the mode.
  • The mode can be found for unequal classes too, but not in Class 10.

13.4

Median of grouped data

The median is the middle-most observation. For ungrouped data in ascending order:

n odd

Median = (n + 12)th observation

n even

Median = average of the (n2)th and (n2 + 1)th

Ungrouped example: marks of 100 students (out of 50)

Median class and the median formula

  1. Find n = Σf and n2. Here n = 53, n2 = 26.5.
  2. The median class is the class whose cf is greater than and nearest to n2: cf 29 > 26.5, so the median class is 60–70.
  3. Read l, cf, f, h and put them in the formula.
Median = l + (n⁄2 − cff) × h
l = lower limit of the median class · n = number of observations · cf = cumulative frequency of the class preceding the median class · f = frequency of the median class · h = class size

Median = 60 + (26.5 − 227) × 10 = 60 + 457 = 66.4

About half the students scored less than 66.4 and half scored more.

Which?

Mean, median or mode: which one to use?

x̄ Mean

Most used. Uses every observation, lies between the smallest and largest, and lets us compare two or more distributions (average results of two schools).
Weakness: extreme values pull it. If one class has frequency 2 and the others 20, 25, 20, 21, 18, the mean is a poor representative.

Median

Best when we want a typical value and extreme values are present: the typical productivity of workers, the average wage in a country. A few billionaires do not move it.

Mode

Best for the most frequent / most popular item: the most watched TV programme, the consumer item in greatest demand, the most common colour of vehicles.

3 Median = Mode + 2 Mean
The empirical relationship between the three measures (Remark 1). Asked as a 1-mark MCQ almost every year. Rearranged: Mode = 3 Median − 2 Mean · Mean = 3 Median − Mode2 · Median = Mode + 2 Mean3

Note

Continuous classes (a note to the reader)

The mode and median formulas assume that the classes are continuous: each class starts exactly where the previous one ends. Classes like 118–126, 127–135 leave gaps. Before using the formulas, close the gaps:

  1. Gap = lower limit of a class − upper limit of the previous class (127 − 126 = 1).
  2. Subtract half the gap from every lower limit and add it to every upper limit.

Traps

Common mistakes

❌ Taking the class with the highest cumulative frequency as the median class

The last class always has the highest cf. The median class is the one whose cf is the first to go above n/2.

❌ Using the median class's own cf

In the median formula, cf is the cumulative frequency of the class before the median class (22 in Table 13.15, not 29).

❌ Swapping f0 and f2

f0 is the class before, f2 the class after. The numerator is f1 − f0. Swapping them gives a wrong mode even though the denominator stays the same.

❌ Using the upper limit for l

l is always the lower limit of the modal or median class.

❌ Using a “less than” table directly

“Less than 30: 27” is a cumulative frequency. Subtract to get class frequencies first (Example 7, CBSE 2023). The modal class in CBSE 2023 Q11 comes from the class frequencies 3, 9, 15, 30, 18, 5, not from the cfs.

❌ Forgetting to make classes continuous

For 118–126, 127–135 … use 117.5–126.5 … before finding the mode or median (Exercise 13.3 Q4, Ex. 13.1 Q5).

❌ Forgetting to add a back

Σfiui ÷ Σfi is ū, not x̄. Multiply by h and add a.

✅ Quick check

The mean, median and mode must lie inside the range of the data, and the mode must lie inside the modal class. If your mode for modal class 40–55 is 58, re-check f0 and f2.

Recap

Summary (NCERT 13.5)

  1. The mean of grouped data: (i) direct method x̄ = ΣfixiΣfi (ii) assumed mean method x̄ = a + ΣfidiΣfi (iii) step-deviation method x̄ = a + (ΣfiuiΣfi) × h, assuming the frequency of each class is centred at its mid-point, the class mark.
  2. The mode of grouped data: Mode = l + (f1 − f02f1 − f0 − f2) × h.
  3. The cumulative frequency of a class is the frequency obtained by adding the frequencies of all the classes preceding it (and the class itself).
  4. The median of grouped data: Median = l + (n/2 − cff) × h.
  5. For the mode and median, the classes must be continuous. 3 Median = Mode + 2 Mean.
