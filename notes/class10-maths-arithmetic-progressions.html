📌 Chapter snapshot

  • AP: a list where each term after the first is got by adding a fixed number d (common difference). General form a, a + d, a + 2d, …
  • Test: a₂ − a₁ = a₃ − a₂ = … = d. Three numbers a, b, c are in AP ⇔ 2b = a + c.
  • nth term: aₙ = a + (n − 1)d. nth term from the end: l − (n − 1)d, where l is the last term.
  • Sum: Sₙ = n/2 [2a + (n − 1)d] = n/2 (a + l). Also aₙ = Sₙ − Sₙ₋₁.
  • Handy sums: 1 + 2 + … + n = n(n + 1)/2 · 1 + 3 + 5 + … (n terms) = n².
  • Most-asked in CBSE: d or a missing term (MCQ), "which term is…", aₙ from Sₙ (2–3 marks), a 5-mark question on Sₙ, and a case study (runs, races, savings). This chapter brings 5 to 9 marks from the 20-mark Algebra unit.
5.1

Patterns around us: what is an AP?

An arithmetic progression (AP) is a list of numbers in which every term, except the first, is obtained by adding the same fixed number to the term before it. That fixed number is the common difference d. It can be positive, negative or zero.

a, a + d, a + 2d, a + 3d, …    d = a₂ − a₁ = a₃ − a₂ = …
💰

Salary

₹8000 a month with a yearly rise of ₹500: 8000, 8500, 9000, … (d = 500)

🚕

Taxi fare

₹15 for the first km and ₹8 for each extra km: 15, 23, 31, … (d = 8)

🌡️

Falling values

Temperature dropping 2° each hour: 10, 8, 6, 4, … (d = −2). A constant list 3, 3, 3 is an AP with d = 0.

Three terms in AP (CBSE 2023)

If p − 1, p + 1 and 2p + 3 are in AP, then 2(p + 1) = (p − 1) + (2p + 3) ⇒ 2p + 2 = 3p + 2 ⇒ p = 0. The terms are −1, 1, 3 ✓

⚡ Smart choice of terms

  • 3 terms in AP: a − d, a, a + d (sum = 3a).
  • 4 terms in AP: a − 3d, a − d, a + d, a + 3d (common difference 2d, sum = 4a).
  • The middle term of an AP with an odd number of terms is the average of all the terms.

Example: three numbers in AP have sum 24 and product 440

Take a − d, a, a + d. Sum 3a = 24 ⇒ a = 8. Product 8(64 − d²) = 440 ⇒ d² = 9 ⇒ d = ±3. Numbers: 5, 8, 11 (or 11, 8, 5).

🧪 Try it nowMatchstick squares

  1. Make 1 square with matchsticks (4 sticks). Attach a second square to its side (7 sticks), then a third (10 sticks).
  2. Write the list 4, 7, 10, … Is it an AP? What is d? (Yes, d = 3: each new square needs 3 sticks.)
  3. Predict the sticks for 20 squares: 4 + 19 × 3 = 61. Build 5 squares and check that you get 4 + 4 × 3 = 16.
5.2

nth term of an AP

To reach the nth term you start at a and add d exactly (n − 1) times. No need to write all the terms in between.

aₙ = a + (n − 1)d

NCERT style: how many three-digit numbers are divisible by 7?

First 105, last 994, d = 7. 994 = 105 + (n − 1)7 ⇒ n − 1 = 127 ⇒ n = 128.

CBSE favourite: aₙ in terms of n

If aₙ = 3 + 4n, then a₁ = 7, a₂ = 11, d = 4. Any aₙ that is linear in n (pn + q) gives an AP with d = p.

⚠️ Watch out

  • It is (n − 1)d, not nd: the first term already counts as one.
  • For "which term is 0" or "first negative term", the answer n must be a natural number: take the next whole number for "first negative".
  • For a decreasing AP, d is negative: 18, 15½, 13, … has d = −5/2.

Example: first negative term of 20, 19¼, 18½, …

d = −3/4. aₙ = 20 − (3/4)(n − 1) < 0 ⇒ n − 1 > 26.67 ⇒ n ≥ 28. The 28th term is the first negative one (a₂₈ = 20 − 81/4 = −1/4).

🧪 Try itCalendar AP

  1. Take this month's calendar. All Mondays form an AP with d = 7.
  2. If the first Monday is the 3rd, the nth Monday is 3 + 7(n − 1). Which Monday is the 24th? 3 + 7(n − 1) = 24 ⇒ n = 4.
  3. Is the 30th a Monday? 3 + 7(n − 1) = 30 ⇒ n − 1 = 27/7: not whole, so no.

5.3

Sum of the first n terms

Legend says a teacher asked young Carl Gauss to add 1 to 100 to keep him busy. He answered in seconds: pair the first and last (1 + 100), the second and second-last (2 + 99), … Every pair makes 101, and there are 50 pairs, so the sum is 5050.

Sₙ = n/2 [2a + (n − 1)d]  =  n/2 (a + l)
ProofDerive Sₙ = n/2 [2a + (n − 1)d] (asked as a 3-mark question)

Sₙ = a + (a + d) + (a + 2d) + … + [a + (n − 1)d] …(1)

Write it in reverse: Sₙ = [a + (n − 1)d] + [a + (n − 2)d] + … + a …(2)

Add (1) and (2) term by term. Each pair adds to 2a + (n − 1)d, and there are n pairs:

2Sₙ = n[2a + (n − 1)d] ⇒ Sₙ = n/2 [2a + (n − 1)d]. Since the last term l = a + (n − 1)d, this is also Sₙ = n/2 (a + l).

Example (NCERT): sum of 22 terms of 8, 3, −2, …

a = 8, d = −5. S₂₂ = 11[16 + 21(−5)] = 11(16 − 105) = −979.

Example: how many terms of 24, 21, 18, … make 78?

n/2[48 + (n − 1)(−3)] = 78 ⇒ n(51 − 3n) = 156 ⇒ 3n² − 51n + 156 = 0 ⇒ n² − 17n + 52 = 0 ⇒ (n − 4)(n − 13) = 0.

Both n = 4 and n = 13 work: the 5th to 13th terms 12, 9, 6, …, −12 add up to zero. Write both answers.

From Sₙ to aₙ (CBSE 2025)

If Sₘ = 2m² + 3m, then a₁ = S₁ = 5, S₂ = 14 ⇒ a₂ = S₂ − S₁ = 9, so d = 4. In general aₙ = Sₙ − Sₙ₋₁ = 4n + 1.

⚡ Shortcuts

  • If Sₙ = pn² + qn, then the AP has d = 2p and a = p + q. Example: Sₙ = 4n − n² gives d = −2, a = 3.
  • Use n/2(a + l) when the last term is known; it saves a step.
  • For "sum of the last k terms", reverse the AP: first term l, common difference −d.

  2. Below them make piles of 6, 5, 4, 3, 2, 1. Every column now has 7 coins, and there are 6 columns: 42 coins.
  3. So 1 + 2 + … + 6 = 42 ÷ 2 = 21 = 6 × 7 / 2. Count to check!

5.4

Word problems: salary, savings, logs, prizes

First decide: does the question want one term (use aₙ) or a total (use Sₙ)? "In the 10th year" ⇒ a₁₀. "In 10 years altogether" ⇒ S₁₀.

Salary (NCERT Ex 5.2)

Subba Rao started work in 1995 at ₹5000 a year, with an increment of ₹200 every year. When did his salary reach ₹7000?

5000 + (n − 1)200 = 7000 ⇒ n = 11. The 11th year is 2005.

Prizes (NCERT Ex 5.3)

₹700 is to be given as 7 cash prizes, each ₹20 less than the one before. Find each prize.

7/2 [2a + 6(−20)] = 700 ⇒ 2a − 120 = 200 ⇒ a = 160. Prizes: ₹160, 140, 120, 100, 80, 60, 40.

Logs (NCERT Ex 5.3 Q19, 5 marks)

200 logs are stacked with 20 in the bottom row, 19 in the next, 18 in the next and so on. How many rows, and how many logs in the top row?

n/2 [40 + (n − 1)(−1)] = 200 ⇒ n(41 − n) = 400 ⇒ n² − 41n + 400 = 0 ⇒ (n − 16)(n − 25) = 0. 2

n = 25 would make a₂₅ = 20 − 24 = −4 logs: impossible. 1 So 16 rows, top row a₁₆ = 20 − 15 = 5 logs. 2

Spiral of 13 semicircles

Lengths l₁, l₂, … = π(0.5), π(1), π(1.5), … Total = π × (0.5 + 1 + … + 6.5) = π × 13/2 × (0.5 + 6.5) = 45.5π = 45.5 × 22/7 = 143 cm.

⚠️ Reject impossible n

When Sₙ = total gives two values of n, test each: a negative number of logs or seats in some row means that n is impossible. When both are valid (like 24, 21, 18, … summing to 78), give both.

🧪 Try itYour savings plan

  1. Plan to save ₹10 this week and ₹5 more each week (10, 15, 20, …).
  2. How much will you save in the 20th week? a₂₀ = 10 + 19 × 5 = ₹105. In 20 weeks altogether? S₂₀ = 10(20 + 95) = ₹1150.
  3. How many weeks to save ₹500? n/2[20 + 5(n − 1)] = 500 ⇒ n² + 3n − 200 = 0 ⇒ n ≈ 12.7, so 13 weeks.

🪜 AP basics

  • a, a + d, a + 2d, …
  • d = a₂ − a₁ (can be −, 0)
  • a, b, c in AP ⇔ 2b = a + c
  • 3 terms: a − d, a, a + d

🎯 nth term

  • aₙ = a + (n − 1)d
  • from end: l − (n − 1)d
  • which term / is it a term?
  • aₙ linear in n ⇒ AP

➕ Sum

  • Sₙ = n/2[2a + (n − 1)d]
  • Sₙ = n/2(a + l)
  • aₙ = Sₙ − Sₙ₋₁
  • Sₙ = pn² + qn ⇒ d = 2p
  • 1 + … + n = n(n + 1)/2

⚠️ Top 8 mistakes students make

  1. Using nd instead of (n − 1)d.
  2. Taking d = a₁ − a₂ (wrong order). Always later minus earlier.
  3. Forgetting that d is negative for a decreasing AP.
  4. Mixing up aₙ (one term) and Sₙ (total) in word problems.
  5. Writing aₙ = Sₙ − Sₙ₊₁. It is Sₙ − Sₙ₋₁.
  6. Accepting n = 25 rows when it gives a negative number of logs in a row.
  7. Counting multiples "between 10 and 250" from 10: start from the first multiple (12).
  8. Arithmetic slips with fractions: 18, 15½, 13 has d = −5/2, not −2.

CBSE exam pattern and how marks are given

The CBSE Class 10 Mathematics (Standard, 041) paper is 80 marks, 3 hours, 38 questions: Section A 20 × 1 (18 MCQs + 2 assertion–reason), B 5 × 2, C 6 × 3, D 4 × 5, E 3 case studies × 4 (1 + 1 + 2). Unit Algebra carries 20 marks; AP often appears as a 5-mark question or a case study.

✍️ How the CBSE marking scheme splits marks

  • 5-mark question: 1 for each correct equation in a and d (2 marks), 1 for solving a and d, 2 for the asked term or sum (formula + answer).
  • Case study (1 + 1 + 2): (i), (ii) a single term each; (iii) a sum, with 1 mark for the correct formula with values and 1 for the answer.
  • 2–3 mark questions: 1 for the formula with substituted values, the rest for the working and answer.

🏆 Answer-writing tips for full marks

  1. Write "Here a = …, d = …, n = …" before using any formula.
  2. Write the formula in symbols first, then substitute. The formula line itself carries marks.
  3. For two unknowns, number the equations (1), (2) and say "(2) − (1)".
  4. State the final answer with units: "Total distance = 370 m".

CBSE 2026 · 30/1/1 · Q6 · 1 markThe common difference of the AP √2, 2√2, 3√2, 4√2, … is (a) 1 (b) √2 (c) 2 (d) 2√2

(b) √2. 2√2 − √2 = √2.

CBSE 2026 · 30/1/1 · Q36 · case study · 4 marksIn a potato race, a bucket is placed at the starting point, 5 m from the first potato. The other potatoes are placed 3 m apart in a straight line; there are 10 potatoes. Each competitor starts from the bucket, picks up the nearest potato, runs back to drop it in the bucket, and continues in the same way until all potatoes are in the bucket. (i) What distance is covered to bring the first potato? (ii) What distance for the second potato? (iii) Find the total distance run. OR (iii) If a competitor runs at 5 m/s, how long does she take in all?

(i) To the first potato and back: 2 × 5 = 10 m. 1

(ii) Second potato is 8 m away: 2 × 8 = 16 m. 1

(iii) Distances 10, 16, 22, … form an AP with a = 10, d = 6, n = 10. 1 S₁₀ = 5[20 + 9 × 6] = 5 × 74 = 370 m. 1

OR (iii) Time = 370 ÷ 5 = 74 s (after finding the total 370 m as above). 2

CBSE 2025 · 30/1/1 · Q11 · 1 markIf the sum of the first m terms of an AP is 2m² + 3m, then its second term is (a) 10 (b) 9 (c) 12 (d) 4

(b) 9. S₁ = 5, S₂ = 8 + 6 = 14, so a₂ = 14 − 5 = 9.

CBSE 2025 · 30/1/1 · Q36 · case study · 4 marksIn a charity run, a participant runs 300 m in the first round and in each next round runs 50 m more than in the round before. She completes 10 rounds. (i) Write the distances of the 4th, 5th and 6th rounds. (ii) Find the distance in the 8th round. (iii) Find the total distance in 10 rounds. OR (iii) Find the total distance in the first 6 rounds.

AP: a = 300, d = 50. (i) a₄ = 300 + 150 = 450 m, a₅ = 500 m, a₆ = 550 m. 1

(ii) a₈ = 300 + 7 × 50 = 650 m. 1

(iii) S₁₀ = 10/2 [600 + 9 × 50] 1 = 5 × 1050 = 5250 m. 1

OR (iii) S₆ = 3[600 + 5 × 50] 1 = 3 × 850 = 2550 m. 1

CBSE 2024 · 30/1/1 · Q4 · 1 markThe first term of an AP is 7, its last term is 84 and the sum of all its terms is 2093/2. The number of terms is (a) 11 (b) 46 (c) 23 (d) 22

(c) 23. n/2 (7 + 84) = 2093/2 ⇒ 91n = 2093 ⇒ n = 23.

CBSE 2024 · 30/1/1 · Q33 (A) · 5 marksThe sum of the first and eighth terms of an AP is 32 and their product is 60. Find the first term and the common difference of the AP. Hence, find the sum of its first 20 terms.

a₁ + a₈ = 2a + 7d = 32 and a(a + 7d) = 60. 1

So a and a + 7d are numbers with sum 32 and product 60: roots of t² − 32t + 60 = 0 ⇒ (t − 30)(t − 2) = 0. 1

Case 1: a = 2, a₈ = 30 ⇒ 7d = 28 ⇒ d = 4. S₂₀ = 10[4 + 19 × 4] = 800. 1½

Case 2: a = 30, a₈ = 2 ⇒ d = −4. S₂₀ = 10[60 − 76] = −160. 1½

CBSE 2024 · 30/1/1 · Q33 (B, OR) · 5 marksAn AP has 40 terms. The sum of its first 9 terms is 153 and the sum of its last 6 terms is 687. Find the first term and common difference. Hence find the sum of all the terms.

S₉ = 9/2 (2a + 8d) = 153 ⇒ a + 4d = 17 …(1) 1

The last 6 terms are a₃₅ to a₄₀: sum = 6/2 (a₃₅ + a₄₀) = 3(2a + 73d) = 687 ⇒ 2a + 73d = 229 …(2) 1½

From (1), a = 17 − 4d ⇒ 34 + 65d = 229 ⇒ d = 3, a = 5. 1

S₄₀ = 20[10 + 39 × 3] = 20 × 127 = 2540. 1½

CBSE 2023 · 30/1/1 · Q3 · 1 markThe value of p for which (p − 1), (p + 1) and (2p + 3) are three consecutive terms of an AP is (a) 0 (b) 1 (c) −1 (d) 2

(a) 0. 2(p + 1) = (p − 1) + (2p + 3) ⇒ p = 0.

CBSE 2023 · 30/1/1 · Q35 (A) · 5 marksThe ratio of the 11th term to the 17th term of an AP is 3 : 4. Find the ratio of the 5th term to the 21st term of the same AP. Also find the ratio of the sum of the first 5 terms to the sum of the first 21 terms.

(a + 10d)/(a + 16d) = 3/4 ⇒ 4a + 40d = 3a + 48d ⇒ a = 8d. 1½

a₅ : a₂₁ = (a + 4d) : (a + 20d) = 12d : 28d = 3 : 7. 1½

S₅ : S₂₁ = 5/2 (2a + 4d) : 21/2 (2a + 20d) = 5 × 20d : 21 × 36d = 100 : 756 = 25 : 189. 2

CBSE 2023 · 30/1/1 · Q35 (B, OR) · 5 marks250 logs are stacked with 22 logs in the bottom row, 21 in the next row, 20 in the row after that, and so on. In how many rows are the 250 logs placed, and how many logs are in the top row?

a = 22, d = −1. n/2 [44 + (n − 1)(−1)] = 250 1

n(45 − n) = 500 ⇒ n² − 45n + 500 = 0 ⇒ (n − 20)(n − 25) = 0. 2

n = 25 gives a₂₅ = 22 − 24 = −2: impossible. 1 So 20 rows, top row a₂₀ = 22 − 19 = 3 logs. 1

📈 Pattern spotted

A case study or 5-mark question every year. 2025 and 2026 used real-life runs and races (case studies); 2023 and 2024 used two-condition problems (ratios, sums of first and last terms) and stacked logs. MCQs: d, p for three terms in AP, n from Sₙ, a₂ from an Sₙ expression.

(a) Both A and R are true and R explains A. (b) Both true, R does not explain A. (c) A true, R false. (d) A false, R true.

AR1A: 3, 6, 9, 12, … is an AP. R: A list is an AP if the difference between consecutive terms is constant.
(a).
AR2A: The sum of the first 10 terms of the AP 1, 3, 5, … is 100. R: The sum of the first n odd natural numbers is n².
(a). 10² = 100.
AR3A: The 11th term of 5, 9, 13, … is 45. R: The nth term of an AP is a + nd.
(c). 5 + 10 × 4 = 45 is true, but the formula is a + (n − 1)d.

a + 3d = 0 ⇒ a = −3d. 1

C4If the mth term of an AP is 1/n and its nth term is 1/m (m ≠ n), show that its (mn)th term is 1.

a + (m − 1)d = 1/n and a + (n − 1)d = 1/m. Subtract: (m − n)d = 1/n − 1/m = (m − n)/mn ⇒ d = 1/mn. 1½

a = 1/n − (m − 1)/mn = 1/mn. ½

a_mn = 1/mn + (mn − 1)/mn = 1. 1
