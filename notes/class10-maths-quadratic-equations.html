📌 Chapter snapshot

  • Standard form: ax² + bx + c = 0, where a, b, c are real numbers and a ≠ 0. Degree 2.
  • Root: α is a root if aα² + bα + c = 0. A quadratic has at most two roots. Roots of the equation = zeroes of the polynomial ax² + bx + c.
  • Two methods in syllabus: factorisation (splitting the middle term) and the quadratic formula x = (−b ± √(b² − 4ac)) / 2a.
  • Discriminant D = b² − 4ac: D > 0 two distinct real roots · D = 0 two equal real roots (−b/2a) · D < 0 no real roots.
  • Removed from syllabus: the completing-the-square method (as a method) and equations reducible to quadratic form.
  • Most-asked in CBSE: nature of roots / value of k for equal roots (MCQ, 2 marks), a word problem on speed, area, numbers or ages (3–5 marks), and a 4-mark case study. This chapter brings 6 to 10 marks from the 20-mark Algebra unit.
4.1

What is a quadratic equation?

A quadratic equation in x is an equation that can be written as ax² + bx + c = 0 with a ≠ 0. The highest power of x is exactly 2. "Quad" means square: the x² term is the heart of it.

ax² + bx + c = 0    (a, b, c real, a ≠ 0)
✅

Quadratic

2x² + x − 300 = 0 · x² = 9 · 3x² − 5x = 0 · (x − 2)² + 1 = 2x − 3

❌

Not quadratic

x + 1/x = 3 (not a polynomial) · x³ − x² = 0 (degree 3) · (x + 1)² = x² + 5 (x² cancels: linear)

🔎

How to check

Expand both sides, bring everything to one side, simplify. If an x² term survives (and nothing higher), it is quadratic.

NCERT style: check whether each is quadratic

(i) (x − 2)² + 1 = 2x − 3 ⇒ x² − 4x + 5 = 2x − 3 ⇒ x² − 6x + 8 = 0: quadratic ✓

(ii) x(x + 1) + 8 = (x + 2)(x − 2) ⇒ x² + x + 8 = x² − 4 ⇒ x + 12 = 0: x² cancels, not quadratic.

(iii) x(2x + 3) = x² + 1 ⇒ x² + 3x − 1 = 0: quadratic ✓

(iv) (x + 2)³ = x³ − 4 ⇒ x³ + 6x² + 12x + 8 = x³ − 4 ⇒ 6x² + 12x + 12 = 0: x³ cancels, quadratic ✓

🌟 Indian connection

Brahmagupta (628 CE) gave a rule to solve ax² + bx = c. Sridharacharya (around 1025 CE) derived the formula we now call the quadratic formula, by completing the square. Babylonians solved "find two numbers whose sum and product are given" problems 4000 years ago, which is exactly a quadratic.

🧪 Try it nowThrow and time

  1. Throw a small ball straight up and catch it. Ask a friend to time it on a phone stopwatch.
  2. If the flight took about 1.2 s, the ball rose for 0.6 s. Its height above your hand was h = 6t − 5t² metres (start speed ≈ 10 × 0.6 = 6 m/s).
  3. Solve 6t − 5t² = 1, i.e. 5t² − 6t + 1 = 0 ⇒ (5t − 1)(t − 1) = 0 ⇒ t = 0.2 s or 1 s. Two times for one height: up and down!

Forming quadratic equations from situations

CBSE often says "represent the situation mathematically" or "form the quadratic equation". Name the unknown, translate each sentence, simplify to ax² + bx + c = 0.

SituationLetEquation
Rectangle: area 528 m², length 1 more than twice breadthbreadth xx(2x + 1) = 528 ⇒ 2x² + x − 528 = 0
Consecutive integers: product 306x, x + 1x(x + 1) = 306 ⇒ x² + x − 306 = 0
Ages: mother 26 years older; product of ages after 3 years is 360Rohan x(x + 3)(x + 29) = 360 ⇒ x² + 32x − 273 = 0
Speed: 480 km; 8 km/h slower takes 3 h morespeed x480/(x − 8) − 480/x = 3 ⇒ x² − 8x − 1280 = 0
Right triangle: altitude 7 less than base, hypotenuse 13base xx² + (x − 7)² = 169 ⇒ x² − 7x − 60 = 0
Sum and product: sum 27, product 182x, 27 − xx(27 − x) = 182 ⇒ x² − 27x + 182 = 0

Worked: the speed equation step by step

Time = distance ÷ speed. Usual time = 480/x h. Slower time = 480/(x − 8) h. Slower takes 3 h more:

480/(x − 8) − 480/x = 3 ⇒ 480[x − (x − 8)] = 3x(x − 8) ⇒ 3840 = 3x² − 24x ⇒ x² − 8x − 1280 = 0.

⚡ Translation tricks

  • "Two consecutive odd/even numbers": x and x + 2.
  • "Sum of two numbers is s": x and s − x. "Reciprocal": 1/x.
  • "Takes t hours less" ⇒ (bigger time) − (smaller time) = t. Slower speed ⇒ more time.
  • "n years ago": subtract n from every person's age.
  • Clear fractions by multiplying both sides by the LCM of the denominators.

🧪 Try itYour own classroom problem

  1. Count the rows and the benches per row in your classroom. Suppose rows = benches + 2 and there are 48 benches in all.
  2. Form the equation: x(x + 2) = 48 ⇒ x² + 2x − 48 = 0.
  3. Solve it after the next section: (x + 8)(x − 6) = 0 ⇒ x = 6 benches per row, 8 rows. Reject x = −8 (you cannot have −8 benches).
4.3

Solving by factorisation: splitting the middle term

If a product is zero, one of the factors is zero. So write ax² + bx + c as (px + q)(rx + s), set each bracket to 0, and read off the two roots.

Find two numbers m and n with m + n = b and m × n = a × c. Then split bx = mx + nx and group.

Example 1 (NCERT): 2x² − 5x + 3 = 0

a × c = 6, b = −5. Two numbers: −2 and −3 (sum −5, product 6).

2x² − 2x − 3x + 3 = 0 ⇒ 2x(x − 1) − 3(x − 1) = 0 ⇒ (2x − 3)(x − 1) = 0

Roots: x = 3/2 and x = 1. Check: 2(1) − 5 + 3 = 0 ✓

Example 2 (NCERT): 6x² − x − 2 = 0

a × c = −12, b = −1 ⇒ −4 and 3. 6x² − 4x + 3x − 2 = 2x(3x − 2) + 1(3x − 2) = (3x − 2)(2x + 1).

Roots: x = 2/3, x = −1/2.

Example 3 (NCERT): 3x² − 2√6 x + 2 = 0

a × c = 6 ⇒ −√6 and −√6 (sum −2√6, product 6). 3x² − √6x − √6x + 2 = √3x(√3x − √2) − √2(√3x − √2) = (√3x − √2)².

Roots: x = √2/√3, √2/√3 (two equal roots).

⚡ Sign table: find m and n faster

a × cbm and nExample
++both positivex² + 7x + 12: 3, 4
+−both negativex² − 7x + 12: −3, −4
−+opposite signs, bigger one positivex² + x − 12: 4, −3
−−opposite signs, bigger one negativex² − x − 12: −4, 3

List factor pairs of |ac| from the middle outward: the pair whose sum or difference is |b| is the one.

⚠️ Common slips

  • Dividing both sides by x in 3x² = 5x loses the root x = 0. Write x(3x − 5) = 0 ⇒ x = 0 or 5/3.
  • (x − 3)(x + 4) = 0 gives x = 3 and x = −4, not +4.
  • Always bring everything to one side first: x² = 4x + 5 ⇒ x² − 4x − 5 = 0.
  • x² = 9 ⇒ x = ±3, not just 3.

🧪 Try itTile rectangles

  1. Cut 1 big square (x²), some long strips (x) and small unit squares from paper, as algebra tiles.
  2. Take 1 big square, 5 strips and 6 small squares (x² + 5x + 6). Arrange them into one perfect rectangle.
  3. Its sides are (x + 2) and (x + 3). The factorisation is the rectangle! Try x² + 7x + 12 next.

4.4

The quadratic formula

Factorisation is quick when nice numbers exist. When they do not (try x² + 4x − 1 = 0), the quadratic formula always works.

x = (−b ± √(b² − 4ac)) / 2a
1️⃣

Write a, b, c

Bring to the form ax² + bx + c = 0 first. Keep the signs: in 3x² − 5x + 2 = 0, b = −5.

2️⃣

Find D

D = b² − 4ac. If D < 0, stop: no real roots.

3️⃣

Plug in

x = (−b + √D)/2a and (−b − √D)/2a. Simplify the surd.

Example (NCERT): 3x² − 5x + 2 = 0

a = 3, b = −5, c = 2. D = 25 − 24 = 1.

x = (5 ± 1)/6 ⇒ x = 1 or x = 2/3.

Example: x² + 4x − 1 = 0 (cannot factorise nicely)

D = 16 + 4 = 20, √20 = 2√5. x = (−4 ± 2√5)/2 = −2 ± √5 (≈ 0.236 and −4.236).

Why?Where does the formula come from? (for understanding; the derivation itself is not asked)

ax² + bx + c = 0. Divide by a: x² + (b/a)x = −c/a.

Add (b/2a)² to both sides: x² + (b/a)x + (b/2a)² = (b/2a)² − c/a ⇒ (x + b/2a)² = (b² − 4ac)/4a².

Take square roots: x + b/2a = ±√(b² − 4ac)/2a ⇒ x = (−b ± √(b² − 4ac))/2a. This is Sridharacharya's method.

🤔 Sum and product of roots (link with Chapter 2)

Adding the two roots: α + β = −b/a. Multiplying: αβ = c/a. For 3x² − 5x + 2 = 0: 1 + 2/3 = 5/3 = −(−5)/3 ✓ and 1 × 2/3 = 2/3 ✓. Use this to check your answers in 10 seconds.

🧪 Try itCalculator check

  1. Solve 2x² + x − 4 = 0 by the formula: D = 1 + 32 = 33, x = (−1 ± √33)/4.
  2. On a calculator, √33 ≈ 5.745, so x ≈ 1.186 or −1.686.
  3. Put x = 1.186 back: 2(1.407) + 1.186 − 4 ≈ 0 ✓. Your root really makes the expression zero.
4.4.1

Discriminant and nature of roots

The number under the root, D = b² − 4ac, discriminates (decides) what kind of roots the equation has, without solving it.

D = b² − 4acNature of rootsGraph of y = ax² + bx + c
D > 0, perfect squaretwo distinct real, rational roots (factorises)cuts x-axis twice
D > 0, not a perfect squaretwo distinct real, irrational rootscuts x-axis twice
D = 0two equal real roots, x = −b/2atouches x-axis once
D < 0no real rootsdoes not meet x-axis

NCERT examples

2x² − 4x + 3 = 0: D = 16 − 24 = −8 < 0 ⇒ no real roots.

3x² − 2x + 1/3 = 0: D = 4 − 4 = 0 ⇒ equal roots, x = 2/6 = 1/3, 1/3.

Finding k (asked every year)

Equal roots: kx² + 2x + 1 = 0 ⇒ D = 4 − 4k = 0 ⇒ k = 1.

Equal roots: 2x² + kx + 3 = 0 ⇒ k² − 24 = 0 ⇒ k = ±2√6.

Equal roots: kx(x − 2) + 6 = 0 ⇒ kx² − 2kx + 6 = 0 ⇒ 4k² − 24k = 0 ⇒ 4k(k − 6) = 0 ⇒ k = 6 (k = 0 rejected: then it is not quadratic).

Real roots: x² + kx + 4 = 0 ⇒ k² − 16 ≥ 0 ⇒ k ≤ −4 or k ≥ 4.

No real roots: x² − 4x + k = 0 ⇒ 16 − 4k < 0 ⇒ k > 4.

NCERT Example: is it possible to put the pole?

A pole is to be fixed on the boundary of a circular park of diameter 13 m so that the difference of its distances from two gates A and B, at the ends of a diameter, is 7 m. Is it possible? How far from the gates?

The angle in a semicircle is 90°, so with distance from B = x and from A = x + 7: x² + (x + 7)² = 13² ⇒ 2x² + 14x − 120 = 0 ⇒ x² + 7x − 60 = 0.

D = 49 + 240 = 289 > 0 ⇒ possible. x = (−7 ± 17)/2 = 5 (reject −12). The pole is 5 m from B and 12 m from A.

⚡ Shortcuts

  • If a and c have opposite signs, then −4ac > 0, so D > 0: real distinct roots for sure.
  • "Real roots" means D ≥ 0 (includes equal). "Distinct real roots" means D > 0.
  • For "equal roots", the answer is often ±: k² = 24 gives two values of k.
  • Equal roots ⇔ the expression is a perfect square, like 4x² − 12x + 9 = (2x − 3)².

Boat and stream (3 marks)

A motorboat whose speed in still water is 18 km/h takes 1 hour more to go 24 km upstream than to return downstream. Find the speed of the stream.

Let stream = x km/h. 24/(18 − x) − 24/(18 + x) = 1 1

24 × 2x = (18 − x)(18 + x) ⇒ 48x = 324 − x² ⇒ x² + 48x − 324 = 0 1

(x + 54)(x − 6) = 0 ⇒ x = 6 (reject −54). Stream speed 6 km/h. 1

Ages (NCERT Ex 4.1): Rohan and his mother

x² + 32x − 273 = 0 ⇒ split 39 and −7: (x + 39)(x − 7) = 0 ⇒ x = 7. Rohan is 7, his mother 33. Check: 10 × 36 = 360 ✓

Cost: the bookseller

A shopkeeper buys some books for ₹80. Had he bought 4 more books for the same ₹80, each would have cost ₹1 less. How many books did he buy?

80/x − 80/(x + 4) = 1 ⇒ 320 = x(x + 4) ⇒ x² + 4x − 320 = 0 ⇒ (x + 20)(x − 16) = 0 ⇒ 16 books (₹5 each).

Work: two taps (5 marks)

Two taps together fill a tank in 9⅜ hours. The larger tap takes 10 hours less than the smaller one. Find the time each takes alone.

Smaller x h, larger (x − 10) h. 1/x + 1/(x − 10) = 8/75 1

75(2x − 10) = 8x(x − 10) ⇒ 8x² − 230x + 750 = 0 ⇒ 4x² − 115x + 375 = 0 2

D = 13225 − 6000 = 7225 = 85². x = (115 ± 85)/8 = 25 or 3.75. 1

x = 3.75 makes x − 10 negative, so reject. Smaller tap 25 h, larger tap 15 h. 1

⚠️ Write the rejection line

CBSE schemes give the last mark only when you state why a root is rejected: "x = −32 is rejected as speed cannot be negative." Never leave two answers when the story allows only one.

Mind map, formulas and common mistakes

QUADRATIC EQUATIONS

📝 Basics

  • ax² + bx + c = 0, a ≠ 0
  • At most 2 roots
  • Check: expand, x² must survive
  • Root α: aα² + bα + c = 0
  • Form from a story

🧮 Solve

  • Split: m + n = b, mn = ac
  • Formula: (−b ± √D)/2a
  • α + β = −b/a, αβ = c/a
  • Reject impossible roots

🔍 Nature

  • D = b² − 4ac
  • D > 0: two distinct real
  • D = 0: equal, −b/2a
  • D < 0: no real roots
  • Equal roots ⇒ D = 0 ⇒ find k
Use factorisation when…Use the formula when…
ac has an easy factor pair adding to bno nice pair exists, or D is not a perfect square
c = 0 (take x common) or b = 0 (x² = k)coefficients are decimals or surds
Example: x² − 5x + 6 = 0Example: x² + 4x − 1 = 0

⚠️ Top 8 mistakes students make

  1. Taking b as +5 in 3x² − 5x + 2 = 0. Signs belong to the coefficients: b = −5.
  2. Forgetting to bring all terms to one side before reading a, b, c.
  3. Writing −b ± √D / 2a with the 2a under √D only. The whole numerator is divided by 2a.
  4. Cancelling x from both sides and losing the root x = 0.
  5. For "equal roots", writing only k = 2√6 and missing k = −2√6.
  6. Not rejecting a negative speed, length or age, or not writing why.
  7. Saying D = 0 means "no roots". It means two equal roots.
  8. In speed problems, putting (faster time) − (slower time) and getting a negative equation.

CBSE exam pattern and how marks are given

The CBSE Class 10 Mathematics (Standard, 041) paper is 80 marks, 3 hours, 38 questions: Section A 20 × 1 (18 MCQs + 2 assertion–reason), B 5 × 2, C 6 × 3, D 4 × 5, E 3 case studies × 4 (1 + 1 + 2). Unit Algebra carries 20 marks; quadratic equations usually brings a long answer or a case study.

✍️ How the CBSE marking scheme splits marks

  • 5-mark word problem: 2 for forming the equation correctly, 2 for solving it (by splitting or formula), 1 for rejecting the invalid root and writing the answer.
  • Case study (1 + 1 + 2): (i) and (ii) form or simplify the equation; (iii) solve or comment on the nature of roots (2 marks: 1 for the method, 1 for the answer).
  • Nature of roots / value of k (2 marks): 1 for writing D = b² − 4ac with the correct condition, 1 for the answer.
  • MCQs: no step marks; one slip costs the mark.

🏆 Answer-writing tips for full marks

  1. Start with "Let the … be x" with units. Examiners look for this line.
  2. Write the equation in standard form and box it before solving.
  3. Show the split (e.g. "−50x + 40x") or write a, b, c and D before using the formula.
  4. Write the rejection reason and end with a sentence answer: "Speed of the train = 40 km/h".

CBSE board questions (2023–2026)

Quadratic Equations questions from CBSE Class 10 Maths Standard papers (set 30/1/1) with full solutions and step marks. Wording lightly shortened.

CBSE 2026 · 30/1/1 · Q33 (A) · 5 marksA train covers 200 km at a uniform speed. Another train, whose speed is 10 km/h less, takes 1 hour more to cover the same distance. Find the speeds of the two trains.

Let the faster train's speed be x km/h; the other's is (x − 10) km/h. 200/(x − 10) − 200/x = 1 1

200[x − (x − 10)] = x(x − 10) ⇒ 2000 = x² − 10x ⇒ x² − 10x − 2000 = 0 1

x² − 50x + 40x − 2000 = 0 ⇒ (x − 50)(x + 40) = 0 ⇒ x = 50 or −40 2

Speed cannot be negative, so x = 50. Speeds: 50 km/h and 40 km/h. Check: 200/40 − 200/50 = 5 − 4 = 1 ✓ 1

CBSE 2026 · 30/1/1 · Q33 (B, OR) · 5 marksThe sum of the areas of two squares is 640 m². If the difference of their perimeters is 64 m, find the sides of the two squares.

Sides x and y (x > y). 4x − 4y = 64 ⇒ x = y + 16. 1

x² + y² = 640 ⇒ (y + 16)² + y² = 640 ⇒ 2y² + 32y − 384 = 0 ⇒ y² + 16y − 192 = 0 1½

(y + 24)(y − 8) = 0 ⇒ y = 8 (reject −24). 1½

x = 24. Sides: 24 m and 8 m. Check: 576 + 64 = 640 ✓ 1

CBSE 2025 · 30/1/1 · Q34 (A) · 5 marksThe perimeter of a right triangle is 60 cm and its hypotenuse is 25 cm. Find the lengths of the other two sides.

Other sides x and 60 − 25 − x = 35 − x. 1

Pythagoras: x² + (35 − x)² = 25² ⇒ 2x² − 70x + 1225 = 625 ⇒ x² − 35x + 300 = 0 2

(x − 15)(x − 20) = 0 ⇒ x = 15 or 20. 1

The other two sides are 15 cm and 20 cm. Check: 15 + 20 + 25 = 60 ✓, 225 + 400 = 625 ✓ 1

CBSE 2025 · 30/1/1 · Q34 (B, OR) · 5 marksA train travels 480 km at a uniform speed. If the speed had been 8 km/h less, it would have taken 3 hours more for the same journey. Find the speed of the train.

Speed x km/h. 480/(x − 8) − 480/x = 3 1

480 × 8 = 3x(x − 8) ⇒ 3840 = 3x² − 24x ⇒ x² − 8x − 1280 = 0 1

x² − 40x + 32x − 1280 = 0 ⇒ (x − 40)(x + 32) = 0 2

x = 40 (speed cannot be −32). Speed = 40 km/h. Check: 480/32 − 480/40 = 15 − 12 = 3 ✓ 1

CBSE 2024 · 30/1/1 · Q3 · 1 markIf the quadratic equation ax² + bx + c = 0 has two real and equal roots, then c is equal to (a) −b/(2a) (b) b/(2a) (c) −b²/(4a) (d) b²/(4a)

(d) b²/(4a). Equal roots ⇒ b² − 4ac = 0 ⇒ ac = b²/4 ⇒ c = b²/(4a).

CBSE 2024 · 30/1/1 · Q36 · case study · 4 marksA floor is covered exactly by 200 square tiles of side x units. If each tile's side were 1 unit longer, 128 tiles would cover the same floor. (i) Write the area of the floor in terms of x. (ii) Form the quadratic equation in x. (iii) Find x and the area of the floor. OR (iii) Find the discriminant of the equation and state the nature of its roots.

(i) Area = 200 × x² = 200x² sq units. 1

(ii) 200x² = 128(x + 1)² ⇒ 25x² = 16(x² + 2x + 1) ⇒ 9x² − 32x − 16 = 0 1

(iii) 9x² − 36x + 4x − 16 = 9x(x − 4) + 4(x − 4) = (9x + 4)(x − 4) = 0 ⇒ x = 4 (reject −4/9). 1 Area = 200 × 16 = 3200 sq units. 1

OR (iii) D = (−32)² − 4(9)(−16) = 1024 + 576 = 1600 > 0 1 and 1600 = 40², so two distinct real (rational) roots. 1

CBSE 2023 · 30/1/1 · Q8 · 1 markThe least positive value of k for which the quadratic equation 2x² + kx − 4 = 0 has rational roots is (a) ±2√2 (b) 2 (c) ±2 (d) √2

(b) 2. Rational roots need D = k² + 32 to be a perfect square. k = 1 gives 33 (no); k = 2 gives 36 = 6² ✓. (±2√2 gives 40, not a perfect square.)

CBSE 2023 · 30/1/1 · Q36 · case study · 4 marksA photo of size 18 cm × 12 cm is to be enlarged by increasing both its length and breadth by the same amount x cm, so that its area becomes double. (i) What is the area of the original photo? (ii) Form the quadratic equation in x. (iii) Find x and the new dimensions. OR (iii) If instead the new area is to be 220 cm², form the equation and comment on its roots.

(i) 18 × 12 = 216 cm². 1

(ii) (18 + x)(12 + x) = 432 ⇒ 216 + 30x + x² = 432 ⇒ x² + 30x − 216 = 0 1

(iii) (x + 36)(x − 6) = 0 ⇒ x = 6 (reject −36). 1 New photo: 24 cm × 18 cm. 1

OR (iii) (18 + x)(12 + x) = 220 ⇒ x² + 30x − 4 = 0. 1 D = 900 + 16 = 916 > 0 but not a perfect square, so the roots are real, distinct and irrational; the useful root is x = (−30 + √916)/2 ≈ 0.13 cm. 1

A1Which of these is a quadratic equation? (a) x(x + 3) = x² + 5 (b) (x + 1)² = 2(x − 3) (c) x³ − x = 0 (d) x + 1/x = 1
(b). x² + 2x + 1 = 2x − 6 ⇒ x² + 7 = 0. (a) becomes linear, (c) is cubic, (d) is not a polynomial equation.

(a). (x − 2)(x − 3) = 0.

(b). 16 − 24 = −8.
A4The values of k for which x² − kx + 9 = 0 has equal roots are (a) ±3 (b) ±6 (c) 6 only (d) ±9
(b). k² − 36 = 0.
A5If x = 2 is a root of x² + kx − 6 = 0, then k = (a) 1 (b) −1 (c) 2 (d) 5
(a). 4 + 2k − 6 = 0.
A6The equation x² + x + 1 = 0 has (a) two distinct real roots (b) two equal roots (c) no real roots (d) more than two roots
(c). D = 1 − 4 = −3.
A7Which equation has two distinct real roots? (a) x² + 2x + 1 = 0 (b) x² + x + 1 = 0 (c) 2x² − 3x − 1 = 0 (d) 4x² − 4x + 1 = 0
(c). D = 9 + 8 = 17 > 0. (a) and (d) have D = 0, (b) has D < 0.
A8If one root of 3x² − 10x + k = 0 is 1/3, then k = (a) 3 (b) −3 (c) 1/3 (d) 10
(a). 3(1/9) − 10/3 + k = 0 ⇒ 1/3 − 10/3 + k = 0 ⇒ k = 3.

Section A: Assertion–Reason (1 mark each)

(a) Both A and R are true and R explains A. (b) Both true, R does not explain A. (c) A true, R false. (d) A false, R true.

AR1A: x² − 4x + 4 = 0 has two equal roots. R: If D = b² − 4ac = 0, the roots are real and equal.
(a). D = 16 − 16 = 0.
AR2A: (x − 1)² = x² + 1 is a quadratic equation. R: A polynomial equation of degree 2 is a quadratic equation.
(d). x² cancels: −2x = 0 is linear. A is false, R is true.

(a). −4ac is positive, so D > 0 whatever b is.

(d). D = 13 is not a perfect square, so the roots are irrational. R is true.

Section B: 2 marks each

B1Solve by factorisation: 2x² + x − 6 = 0.

ac = −12, b = 1 ⇒ 4 and −3: 2x² + 4x − 3x − 6 = 2x(x + 2) − 3(x + 2) = (2x − 3)(x + 2). 1

x = 3/2 or x = −2. 1

B2Find k so that kx² − 2√5 x + 4 = 0 has equal roots.

D = (2√5)² − 16k = 20 − 16k = 0. 1

k = 20/16 = 5/4. 1

B3Find the nature of the roots of 2x² − 2√6 x + 3 = 0. If real roots exist, find them.

D = 24 − 24 = 0 ⇒ two equal real roots. 1

x = −b/2a = 2√6/4 = √6/2, √6/2. 1

B4Solve: √3 x² + 10x + 7√3 = 0.

ac = √3 × 7√3 = 21 ⇒ 3 and 7: √3x² + 3x + 7x + 7√3 = √3x(x + √3) + 7(x + √3) = (x + √3)(√3x + 7). 1

x = −√3 or x = −7/√3 = −7√3/3. 1

B5The product of two consecutive odd natural numbers is 143. Find the numbers.

x(x + 2) = 143 ⇒ x² + 2x − 143 = 0 ⇒ (x + 13)(x − 11) = 0. 1

x = 11 (natural). Numbers 11 and 13. 1

Section C: 3 marks each

C1Solve by the quadratic formula: x² − (√3 + 1)x + √3 = 0.

a = 1, b = −(√3 + 1), c = √3. D = (√3 + 1)² − 4√3 = 4 + 2√3 − 4√3 = 4 − 2√3 = (√3 − 1)². 1½

x = [(√3 + 1) ± (√3 − 1)]/2 ⇒ x = √3 or x = 1. 1½

C2If −5 is a root of 2x² + px − 15 = 0 and the equation p(x² + x) + k = 0 has equal roots, find k.

2(25) − 5p − 15 = 0 ⇒ p = 7. 1

7x² + 7x + k = 0 has equal roots ⇒ 49 − 28k = 0 1

k = 7/4. 1

C3The sum of the reciprocals of Rehman's ages (in years) 3 years ago and 5 years from now is 1/3. Find his present age.

1/(x − 3) + 1/(x + 5) = 1/3 ⇒ 3(2x + 2) = (x − 3)(x + 5) 1

6x + 6 = x² + 2x − 15 ⇒ x² − 4x − 21 = 0 ⇒ (x − 7)(x + 3) = 0 1

Age cannot be negative: Rehman is 7 years old. 1

C4The diagonal of a rectangular field is 60 m more than its shorter side. The longer side is 30 m more than the shorter side. Find the sides.

Shorter side x: x² + (x + 30)² = (x + 60)² 1

2x² + 60x + 900 = x² + 120x + 3600 ⇒ x² − 60x − 2700 = 0 ⇒ (x − 90)(x + 30) = 0 1

x = 90. Sides 90 m and 120 m (diagonal 150 m). 1

Section D: 5 marks

D1An express train takes 1 hour less than a passenger train to travel 132 km between Mysuru and Bengaluru. The average speed of the express train is 11 km/h more than that of the passenger train. Find the average speeds of the two trains.

Passenger x km/h, express (x + 11) km/h. 132/x − 132/(x + 11) = 1 1

132 × 11 = x(x + 11) ⇒ x² + 11x − 1452 = 0 1

D = 121 + 5808 = 5929 = 77². x = (−11 ± 77)/2 = 33 or −44. 2

Speeds: passenger 33 km/h, express 44 km/h (−44 rejected). 1

D2A rectangular park is to be designed whose breadth is 3 m less than its length. Its area is to be 4 m² more than the area of a park shaped like an isosceles triangle with its base as the breadth of the rectangular park and altitude 12 m. Find the length and breadth of the rectangular park.

Length x, breadth x − 3. x(x − 3) = ½(x − 3)(12) + 4 2

x² − 3x = 6x − 14 ⇒ x² − 9x + 14 = 0 ⇒ (x − 2)(x − 7) = 0 2

x = 2 gives breadth −1 (reject). Length 7 m, breadth 4 m. 1

D3A takes 6 days less than B to finish a piece of work. Working together they finish it in 4 days. How long would each take alone?

A alone x days, B (x + 6) days. 1/x + 1/(x + 6) = 1/4 1

4(2x + 6) = x(x + 6) ⇒ x² − 2x − 24 = 0 2

(x − 6)(x + 4) = 0 ⇒ x = 6. 1

A takes 6 days, B 12 days. Check: 1/6 + 1/12 = 1/4 ✓ 1

Section E: Case study (1 + 1 + 2)

E1During a school sports day a ball is thrown up from the top of a 25 m building. Its height after t seconds is h = −5t² + 20t + 25 metres. (i) What is the height at t = 0? (ii) After how many seconds does the ball hit the ground? (iii) At what times is the ball 40 m high? OR (iii) Can the ball ever reach 50 m? Justify using the discriminant.

(i) h(0) = 25 m. 1

(ii) −5t² + 20t + 25 = 0 ⇒ t² − 4t − 5 = 0 ⇒ (t − 5)(t + 1) = 0 ⇒ t = 5 s. 1

(iii) −5t² + 20t + 25 = 40 ⇒ t² − 4t + 3 = 0 ⇒ (t − 1)(t − 3) = 0 1 ⇒ at 1 s (going up) and 3 s (coming down). 1

OR (iii) −5t² + 20t + 25 = 50 ⇒ t² − 4t + 5 = 0, D = 16 − 20 = −4 < 0 1 ⇒ no real t: the ball never reaches 50 m (its maximum is 45 m at t = 2 s). 1

E2Priya plans a rectangular kitchen garden. Its length is 2 m more than twice its breadth, and its area is 60 m². (i) Form the quadratic equation. (ii) Find the breadth and length. (iii) Fencing costs ₹20 per metre. Find the cost of fencing. OR (iii) If the area were 70 m² instead, what would be the nature of the roots of the new equation?

(i) x(2x + 2) = 60 ⇒ 2x² + 2x − 60 = 0 ⇒ x² + x − 30 = 0. 1

(ii) (x + 6)(x − 5) = 0 ⇒ breadth 5 m, length 12 m. 1

(iii) Perimeter = 2(12 + 5) = 34 m 1; cost = 34 × 20 = ₹680. 1

OR (iii) x² + x − 35 = 0, D = 1 + 140 = 141 > 0, not a perfect square 1 ⇒ two distinct irrational real roots; breadth = (−1 + √141)/2 ≈ 5.44 m. 1

Exercise 4.1

1Check whether the following are quadratic equations: (i) (x + 1)² = 2(x − 3) (ii) x² − 2x = (−2)(3 − x) (iii) (x − 2)(x + 1) = (x − 1)(x + 3) (iv) (x − 3)(2x + 1) = x(x + 5) (v) (2x − 1)(x − 3) = (x + 5)(x − 1) (vi) x² + 3x + 1 = (x − 2)² (vii) (x + 2)³ = 2x(x² − 1) (viii) x³ − 4x² − x + 1 = (x − 2)³

(i) x² + 2x + 1 = 2x − 6 ⇒ x² + 7 = 0: quadratic.

(ii) x² − 2x = −6 + 2x ⇒ x² − 4x + 6 = 0: quadratic.

(iii) x² − x − 2 = x² + 2x − 3 ⇒ −3x + 1 = 0: not quadratic.

(iv) 2x² − 5x − 3 = x² + 5x ⇒ x² − 10x − 3 = 0: quadratic.

(v) 2x² − 7x + 3 = x² + 4x − 5 ⇒ x² − 11x + 8 = 0: quadratic.

(vi) x² + 3x + 1 = x² − 4x + 4 ⇒ 7x − 3 = 0: not quadratic.

(vii) x³ + 6x² + 12x + 8 = 2x³ − 2x ⇒ x³ − 6x² − 14x − 8 = 0: degree 3, not quadratic.

(viii) x³ − 4x² − x + 1 = x³ − 6x² + 12x − 8 ⇒ 2x² − 13x + 9 = 0: quadratic.

2Represent the following situations as quadratic equations: (i) The area of a rectangular plot is 528 m². The length of the plot is one more than twice its breadth. Find the length and breadth. (ii) The product of two consecutive positive integers is 306. Find the integers. (iii) Rohan's mother is 26 years older than him. The product of their ages 3 years from now will be 360. Find Rohan's present age. (iv) A train travels 480 km at a uniform speed. If the speed had been 8 km/h less, it would have taken 3 hours more. Find the speed of the train.

(i) Breadth x: x(2x + 1) = 528 ⇒ 2x² + x − 528 = 0. (Solving: x = 16, so 33 m × 16 m.)

(ii) x(x + 1) = 306 ⇒ x² + x − 306 = 0. (x = 17: 17 and 18.)

(iii) (x + 3)(x + 29) = 360 ⇒ x² + 32x − 273 = 0. (x = 7 years.)

(iv) 480/(x − 8) − 480/x = 3 ⇒ x² − 8x − 1280 = 0. (x = 40 km/h.)

Exercise 4.2

1Find the roots by factorisation: (i) x² − 3x − 10 = 0 (ii) 2x² + x − 6 = 0 (iii) √2 x² + 7x + 5√2 = 0 (iv) 2x² − x + 1/8 = 0 (v) 100x² − 20x + 1 = 0

(i) x² − 5x + 2x − 10 = (x − 5)(x + 2) ⇒ 5, −2.

(ii) 2x² + 4x − 3x − 6 = (2x − 3)(x + 2) ⇒ 3/2, −2.

(iii) √2x² + 5x + 2x + 5√2 = x(√2x + 5) + √2(√2x + 5) = (√2x + 5)(x + √2) ⇒ −5/√2, −√2.

(iv) × 8: 16x² − 8x + 1 = (4x − 1)² ⇒ 1/4, 1/4.

(v) (10x − 1)² = 0 ⇒ 1/10, 1/10.

2(i) John and Jivanti together have 45 marbles. Both of them lost 5 marbles each, and the product of the number of marbles they now have is 124. Find how many marbles they had to start with. (ii) A cottage industry produces a certain number of toys in a day. The cost of production of each toy (in rupees) was 55 minus the number of toys produced that day. On a particular day the total cost of production was ₹750. Find the number of toys produced that day.

(i) John x, Jivanti 45 − x. (x − 5)(40 − x) = 124 ⇒ x² − 45x + 324 = 0 ⇒ (x − 36)(x − 9) = 0. They had 36 and 9 marbles (either way round).

(ii) x(55 − x) = 750 ⇒ x² − 55x + 750 = 0 ⇒ (x − 25)(x − 30) = 0. 25 or 30 toys.

3Find two numbers whose sum is 27 and product is 182.
x(27 − x) = 182 ⇒ x² − 27x + 182 = 0 ⇒ (x − 13)(x − 14) = 0. Numbers 13 and 14.
4Find two consecutive positive integers, the sum of whose squares is 365.
x² + (x + 1)² = 365 ⇒ 2x² + 2x − 364 = 0 ⇒ x² + x − 182 = 0 ⇒ (x + 14)(x − 13) = 0. Integers 13 and 14.
5The altitude of a right triangle is 7 cm less than its base. If the hypotenuse is 13 cm, find the other two sides.
x² + (x − 7)² = 169 ⇒ 2x² − 14x − 120 = 0 ⇒ x² − 7x − 60 = 0 ⇒ (x − 12)(x + 5) = 0. Base 12 cm, altitude 5 cm.
6A cottage industry produces a certain number of pottery articles in a day. On a particular day, the cost of production of each article (in rupees) was 3 more than twice the number of articles produced that day. If the total cost of production that day was ₹90, find the number of articles produced and the cost of each article.
x(2x + 3) = 90 ⇒ 2x² + 3x − 90 = 0 ⇒ 2x² + 15x − 12x − 90 = (2x + 15)(x − 6) = 0 ⇒ x = 6. 6 articles, ₹15 each.

Exercise 4.3 (nature of roots)

1Find the nature of the roots. If real roots exist, find them: (i) 2x² − 3x + 5 = 0 (ii) 3x² − 4√3 x + 4 = 0 (iii) 2x² − 6x + 3 = 0

(i) D = 9 − 40 = −31 < 0 ⇒ no real roots.

(ii) D = 48 − 48 = 0 ⇒ equal roots x = 4√3/6 = 2/√3, 2/√3.

(iii) D = 36 − 24 = 12 > 0 ⇒ distinct real roots x = (6 ± 2√3)/4 = (3 ± √3)/2.

2Find k so that each equation has two equal roots: (i) 2x² + kx + 3 = 0 (ii) kx(x − 2) + 6 = 0

(i) k² − 24 = 0 ⇒ k = ±2√6.

(ii) kx² − 2kx + 6 = 0 ⇒ 4k² − 24k = 0 ⇒ k = 0 or 6. k = 0 makes it not quadratic, so k = 6.

3Is it possible to design a rectangular mango grove whose length is twice its breadth and whose area is 800 m²? If so, find its length and breadth.
x(2x) = 800 ⇒ x² − 400 = 0. D = 1600 > 0, so yes. x = 20. Breadth 20 m, length 40 m.
4Is the following situation possible? If so, find their present ages. The sum of the ages of two friends is 20 years. Four years ago, the product of their ages in years was 48.
(x − 4)(16 − x) = 48 ⇒ x² − 20x + 112 = 0. D = 400 − 448 = −48 < 0 ⇒ no real roots: the situation is not possible.
5Is it possible to design a rectangular park of perimeter 80 m and area 400 m²? If so, find its length and breadth.
l + b = 40, l(40 − l) = 400 ⇒ l² − 40l + 400 = 0. D = 1600 − 1600 = 0 ⇒ equal roots l = 20. Yes: 20 m × 20 m (a square park).
